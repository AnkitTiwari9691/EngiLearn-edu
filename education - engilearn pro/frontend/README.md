# EngiLearn Platform

Static engineering education platform split from one large HTML file into a maintainable folder structure.

## Structure

- `index.html` - main page shell and section markup
- `assets/css/` - main, auth, tools, and responsive styles
- `assets/js/` - page rendering, auth, tools, and animation scripts
- `components/` - reusable HTML section references
- `pages/` - starter dashboard, profile, and courses pages
- `data/` - branch, PYQ, and video data
- `manifest.json` and `sw.js` - PWA metadata and cache worker

## Run

Open `index.html` in a browser, or serve the folder with any static server.
